# bioc-devel

Bioconductor development

Automated mbox archive. Updated daily via GitHub Actions.

## Structure

- `raw/` - Monthly .mbox files downloaded from [https://stat.ethz.ch/pipermail/bioc-devel/](https://stat.ethz.ch/pipermail/bioc-devel/)
- `processed/` - Structured JSON output from rmail-parser
- `meta.json` - List statistics

## Viewer

Browse these archives at [archives.rstats.dev](https://archives.rstats.dev/lists/bioc-devel/)
